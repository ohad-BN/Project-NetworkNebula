Milestone 1: Real AI Model Execution (Replacing Simulation)
Real Inference Engine (vLLM / llama.cpp / Ollama):
Connect the Celery worker to a real local LLM engine (such as vLLM
 or 4-bit quantized llama-cpp-python).
When a customer types a prompt in the Playground or calls POST /v1/chat/completions, an actual neural network running on your RTX 4070 processes the prompt and streams back real intelligent tokens.
Real LoRA Training (PEFT / Unsloth):
In app/worker.py, wire real PyTorch backpropagation using Hugging Face peft and bitsandbytes (QLoRA 4-bit) so customer JSONL datasets produce genuinely fine-tuned adapter weights.
Milestone 2: The Standalone "Nebula Worker" CLI Agent
Right now: The worker runs inside your full project repository.
In Alpha: A GPU owner on another computer anywhere in the world should not have to clone your entire web application. They should be able to run a lightweight standalone command:
powershell
pip install nebula-worker
nebula-worker join --server https://api.networknebula.ai --key <worker_key>
Firewall / NAT Traversal: Use a persistent WebSocket or gRPC tunnel so remote home GPUs can receive jobs without needing to open router ports.
Milestone 3: Real Billing & Automated Payouts
Customer Deposits (Inflow):
Integrate Stripe (credit cards) or Crypto (USDC on Solana / Base) on /wallet/deposit so companies can top up balance with real money.
Worker Withdrawals (Outflow):
Connect /wallet/withdraw to automated payouts (PayPal Payouts API or Crypto wallet transfers) once a host worker reaches the $10.00 threshold.
Milestone 4: Public Cloud Deployment (Live on the Internet)
Deploy the Orchestrator, Database, Redis, and MinIO S3 onto a public cloud server (e.g. Hetzner / AWS / DigitalOcean, ~$15–$30/month) with SSL HTTPS domains:
console.networknebula.ai (The React 19 Frontend Web Console)
api.networknebula.ai (The FastAPI & OpenAI Gateway)
s3.networknebula.ai (The MinIO S3 Storage Fabric)
